字阶与排版规则

衬线只给标题，正文和 UI 全用无衬线；等宽只给需要逐字符比对的内容。这是 Claude 风格的关键混排比例。

--fs-3xl / 28 / serif 400EasyCharles
--fs-xl / 18 / serif 400规则（JSON）
--fs-lg / 15 / serif 400Xiaomi 14 · Android 15
--fs-md / 13 / sans 400设备名、正文、按钮 —— 界面基准字号
--fs-sm / 12 / sans 400列表行、说明文字、时间戳
--fs-xs / 11 / mono/v1/user/profile?id=10231
--fs-micro / 10 / 700 mock 流式 METHOD / 耗时 / 分组标题
  • 标题用衬线（Georgia 兜底），正文用系统无衬线 —— 这是最容易被忽略但最提升质感的一条
  • URL / header / body / 状态码 / 耗时 → 等宽，因为要按字符比对
  • 中文正文不要上衬线，Georgia 没有中文字形会回退到系统衬线，混排会脏
  • 方法徽章是唯一允许「无衬线加粗 + 浅底」的彩色元素，其他一律走语义色

落地方式

1 · 变量注入

  • 把 :root 拆成 6 组 [data-family][data-mode]
  • 常量（间距/圆角/字阶）与色值分离
  • 组件 CSS 只写 var(--xx)，不出现字面色值

2 · 模式记忆

  • localStorage['ec_theme'] 存 family:mode
  • 首次访问读 prefers-color-scheme
  • 加一行「跟随系统」选项，可覆盖默认值

3 · 结构增强

  • 详情区改「请求/响应/规则/时间线」四页签，长 JSON 不再无限拉长
  • 搜索框加 mock / 流式筛选段
  • 列表补 3xx 与「缓存」标签

推荐组合：默认 Claude 暖调 + 深夜，明色作为跟随系统的白天模式；冷调保留为「经典」选项， 霓虹只留配色不做默认。调试工具使用时长以小时计，深夜做默认能显著减轻疲劳。
